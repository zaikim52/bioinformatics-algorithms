# Bioinformatics Algorithms - Code Challenges

Python solutions to the code challenges in *Bioinformatics Algorithms: An Active Learning Approach* solved on [Rosalind Textbook Track](https://rosalind.info/problems/list-view/?location=bioinformatics-textbook-track).

## Contents
- **Chapter 01** : Where in the Genome Does DNA Replication Begin?
- **Chapter 02** : Which DNA Patterns Play the Role of Molecular Clocks?

## Structure
```
ch01/ Chapter 1 solutions
ch02/ Chapter 2 solutions
data/ Sample datasets
utils.py Shared functions
```

## Usage
```bash
python ch01/ba1a_pattern_count.py data/rosalind_ba1a.txt
```
